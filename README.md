# 🌆 City Skyline

A responsive **City Skyline** built using pure **HTML and CSS**. The project uses CSS gradients, shapes, repeating patterns, and responsive design to create a stylized skyline without JavaScript or external libraries.

## 🚀 Live Demo

**[View City Skyline](https://ishan13-dev.github.io/City-Skyline/)**

## 🛠️ Technologies Used

* HTML5
* CSS3
* CSS Variables
* CSS Gradients
* Flexbox
* Responsive Design
* GitHub Pages

## ✨ Features

* 🌇 Layered background and foreground buildings
* 🪟 CSS-generated windows and building patterns
* 🎨 CSS variables for building and window colors
* 🌅 Radial gradient sky
* 📱 Responsive design using CSS media queries
* ⚡ No JavaScript required
* 📦 No external libraries or frameworks

## 🎯 What I Learned

Through this project, I practiced:

* Structuring a webpage with semantic HTML
* Connecting HTML with an external CSS stylesheet
* Using CSS Flexbox for layout
* Creating visual shapes using CSS borders
* Using `linear-gradient()` and `radial-gradient()`
* Creating repeating patterns with `repeating-linear-gradient()`
* Using CSS custom properties (`--variables`)
* Building responsive layouts with `@media` queries
* Deploying a website using GitHub Pages
